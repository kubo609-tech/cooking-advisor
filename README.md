# 大人の自炊塾

これから単身赴任・一人暮らしを始める50代の料理初心者向けに、健康的な食生活を自炊で維持できるようになることを目指した**料理学習Webアプリ**です。単なるレシピ集ではなく、初心者が本格的な料理技術を段階的に身につけられる学習ツールとして設計しています。

## 特徴

- **単一ファイル完結 / オフライン動作** — `index.html` をブラウザで開くだけで基本機能が動作します。ビルドツール・npm・外部CDNは不要です(後述の「AIでレシピ下書き」だけは任意のオンライン機能)。
- **条件からメニュー提示** — 国・料理ジャンル、食事区分、人数、好み条件(苦手食材の除外・辛さ・調理時間・カロリー志向)で絞り込み。
- **栄養バランス表示** — 指定人数分に換算したエネルギー・たんぱく質・脂質・炭水化物・塩分相当量と、栄養面の特徴コメント。
- **食材・調味料リスト** — 指定人数に応じて分量を自動スケーリング。チェック状態は `localStorage` に保存され、買い物リストとして使えます。
- **調理器具リスト** — 特殊な器具には代用方法を注記。
- **初心者向け調理手順** — ステップごとの目安時間、つまずきポイントのコツ、専門用語の注釈、簡易イラスト(インラインSVG)、完了チェック機能。
- **出来上がりイメージ** — 外部画像に依存せず、インラインSVGイラストで表示。
- **メニュー追加** — フォームから自分のレシピ(食材・調味料・器具・手順・栄養・完成イラスト)を登録・編集・削除できます。登録したレシピは条件検索やメニュー一覧に組み込まれ、`localStorage` に保存されます。
- **AIでレシピ下書き(任意・オンライン)** — 料理名を入力すると、Anthropic (Claude) API を使って食材・分量・手順・栄養の下書きを自動生成し、追加フォームに反映します。手入力が難しい初心者向けの補助機能です。詳細は下記「AIでレシピ下書き」を参照。
- **レスポンシブ対応** — スマートフォン・PC双方で崩れないレイアウト。50代でも読みやすい大きめの文字とコントラストの高い配色。

## 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をWebブラウザで開きます(ダブルクリック)。

ネットワーク接続は不要です。

## 画面フロー

1. **トップ画面** — アプリの説明と条件指定フォーム。
2. **候補一覧画面** — 条件に合致するレシピをカード表示。
3. **レシピ詳細画面** — 完成イメージ / 栄養情報 / 食材・調味料リスト / 調理器具リスト / 調理手順。人数変更に応じて分量・栄養値がリアルタイム再計算されます。自作レシピにはこの画面から編集・削除ができます。
4. **メニュー追加画面** — ヘッダーの「メニュー追加」から開き、フォームに入力して自分のレシピを登録します。

画面遷移はページ遷移ではなく、同一HTML内でのSPA的な表示切替で実装しています。

## AIでレシピ下書き

料理初心者が食材・分量・手順をゼロから入力するのは負担が大きいため、料理名から下書きを自動生成する補助機能を用意しています。

- **仕組み** — ブラウザから Anthropic Messages API (`api.anthropic.com`) を直接呼び出し、ツール(構造化出力)でレシピJSONを受け取って追加フォームに反映します。生成結果は必ず確認・修正してから登録してください(分量・栄養値は目安です)。
- **必要なもの** — Anthropic (Claude) の APIキー。追加画面の「AIアシスタント設定(APIキー)」で入力・保存します。
  - キーとモデル選択は **この端末の `localStorage` のみ** に保存されます。送信先は `api.anthropic.com` だけです。共有PCでの使用や、キーの取り扱いにご注意ください。
  - 使用モデルは Opus 5 / Sonnet 5 / Haiku 4.5 から選べます(既定は Opus 5。コスト重視なら Sonnet 5 / Haiku 4.5)。生成のたびに Anthropic の利用料が発生します。
- **オンライン必須 / 実行方法** — この機能だけはネット接続が必要です。`file://`(ファイルをダブルクリック)で開くとブラウザの制限で通信できないことがあります。その場合は次のいずれかで**URL経由**で開いてください。
  - GitHub Pages を有効化する: リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`** を選択。数十秒後に `https://kubo609-tech.github.io/cooking-advisor/` で開けます。
  - ローカルで簡易サーバを立てる: リポジトリ直下で `python3 -m http.server` を実行し、`http://localhost:8000/` を開く。
- **オフライン時** — AIパネルの生成ボタンはエラーを表示するだけで、それ以外の機能(手動追加・検索・一覧・詳細)は従来どおり動作します。
